# Prep Sheet Content Rules

These rules load only when the skill runs (progressive disclosure), keeping the
SKILL.md body short.

## Must always include
- A clear title with the non-identifying patient label.
- The daily schedule grouped by time of day.
- Any interactions found, **highest severity first**, with a plain-language
  mechanism and the "review with a professional" advice.
- A footer disclaimer: this sheet is an organiser, not medical advice, and every
  item should be confirmed with a pharmacist or doctor.

## Must never include
- Dosing recommendations, dose changes, or "you should stop/start X".
- A diagnosis or interpretation of symptoms.
- Any identifier beyond the short label the user chose (no full names, DOB, IDs).

## Severity vocabulary
Use exactly: **MAJOR**, **MODERATE**, **MINOR** (uppercase) so the sheet is
skimmable. If no interactions are found, state that explicitly rather than
leaving the section blank (avoids implying "checked = safe").
